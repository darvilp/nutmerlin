# ADR 0006: Repository and license defaults

- Status: Accepted
- Date: 2026-08-01

## Decision

Use these project defaults:

- GitHub repository: `danielarvilpayne/nutmerlin`
- public visibility
- GPL-3.0-or-later license
- GitHub Actions for host CI
- `main` as the protected default branch
- feature branches and draft pull requests for Codex work

Hardware workflows are manually triggered and are not required for ordinary pull requests.
